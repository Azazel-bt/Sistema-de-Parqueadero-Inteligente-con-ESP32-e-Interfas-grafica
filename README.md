# Sistema-de-Parqueadero-Inteligente-con-ESP32-e-Interfas-grafica
Proyecto IoT basado en ESP32 para la automatización y monitoreo en tiempo real de un parqueadero de 4 plazas, utilizando sensores de efecto Hall analógicos, servomotores para control de barreras y un servidor web integrado con interfaz interactiva.
